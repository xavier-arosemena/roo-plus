Roo+ es un **fork de Zoo Code**: un asistente de desarrollo con IA con **90 modos personalizados precargados** de un catálogo de **301 modos**, además de soporte para **MCP** y **más de 25 proveedores**.

## Instalación

1. Abre **VS Code** o **VS Codium**.
2. Ve a **Extensiones** (`Ctrl+Shift+X` / `Cmd+Shift+X`).
3. Busca **"Roo+"**.
4. Haz clic en **Instalar**.

O instálalo directamente desde la línea de comandos:

```bash
code --install-extension xavier-arosemena.roo-plus
ovsx install xavier-arosemena/roo-plus
```

O compílalo desde el código fuente siguiendo la sección [Guía de inicio rápido](../../README.md#quick-start) del README en inglés.
