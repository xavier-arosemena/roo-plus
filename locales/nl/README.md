Roo+ is een **fork van Zoo Code**: een AI-ontwikkelassistent met **90 vooraf geladen aangepaste modi** uit een catalogus van **301 modi**, plus **MCP-ondersteuning** en **meer dan 25 providers**.

## Installatie

1. Open **VS Code** of **VS Codium**.
2. Ga naar **Extensies** (`Ctrl+Shift+X` / `Cmd+Shift+X`).
3. Zoek naar **"Roo+"**.
4. Klik op **Installeren**.

Of installeer het rechtstreeks vanaf de opdrachtregel:

```bash
ovsx install xavier-arosemena/roo-plus
```

Of bouw het vanuit de broncode door de sectie [Snel aan de slag](../../README.md#quick-start) van de Engelse README te volgen.
