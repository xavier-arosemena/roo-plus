Roo+ là một **nhánh fork của Zoo Code**: trợ lý phát triển AI với **90 chế độ tùy chỉnh được tải sẵn** từ danh mục **301 chế độ**, cùng hỗ trợ **MCP** và **hơn 25 nhà cung cấp**.

## Cài đặt

1. Mở **VS Code** hoặc **VS Codium**.
2. Vào mục **Extensions** (`Ctrl+Shift+X` / `Cmd+Shift+X`).
3. Tìm kiếm **"Roo+"**.
4. Nhấp vào **Cài đặt**.

Hoặc cài đặt trực tiếp từ dòng lệnh:

```bash
code --install-extension xavier-arosemena.roo-plus
ovsx install xavier-arosemena/roo-plus
```

Hoặc biên dịch từ mã nguồn theo phần [Bắt đầu nhanh](../../README.md#quick-start) trong README tiếng Anh.
