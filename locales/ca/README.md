Roo+ és un **fork de Zoo Code**: un assistent de desenvolupament amb IA amb **90 modes personalitzats preinstal·lats** d'un catàleg de **301 modes**, a més de suport per a **MCP** i **més de 25 proveïdors**.

## Instal·lació

1. Obre **VS Code** o **VS Codium**.
2. Ves a **Extensions** (`Ctrl+Shift+X` / `Cmd+Shift+X`).
3. Cerca **"Roo+"**.
4. Fes clic a **Instal·la**.

O instal·la'l directament des de la línia d'ordres:

```bash
code --install-extension xavier-arosemena.roo-plus
ovsx install xavier-arosemena/roo-plus
```

O compila'l des del codi font seguint la secció [Guia d'inici ràpid](../../README.md#quick-start) del README en anglès.
