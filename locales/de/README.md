Roo+ ist ein **Fork von Zoo Code**: ein KI-Entwicklungsassistent mit **90 vorinstallierten benutzerdefinierten Modi** aus einem Katalog von **301 Modi**, plus **MCP-Unterstützung** und **über 25 Providern**.

## Installation

1. Öffne **VS Code** oder **VS Codium**.
2. Gehe zu **Erweiterungen** (`Ctrl+Shift+X` / `Cmd+Shift+X`).
3. Suche nach **"Roo+"**.
4. Klicke auf **Installieren**.

Oder installiere es direkt über die Kommandozeile:

```bash
ovsx install xavier-arosemena/roo-plus
```

Oder baue es aus dem Quellcode, indem du dem Abschnitt [Schnellstart](../../README.md#quick-start) im englischen README folgst.
