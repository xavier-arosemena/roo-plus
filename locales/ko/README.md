Roo+는 **Zoo Code의 포크**입니다. **301개 모드 카탈로그**에서 **90개의 맞춤형 모드**를 사전 로드한 AI 개발 어시스턴트로, **MCP 지원**과 **25개 이상의 공급자**를 제공합니다.

## 설치

1. **VS Code** 또는 **VS Codium**을 엽니다.
2. **확장 프로그램**으로 이동합니다 (`Ctrl+Shift+X` / `Cmd+Shift+X`).
3. **"Roo+"**를 검색합니다.
4. **설치**를 클릭합니다.

또는 명령줄에서 직접 설치합니다:

```bash
ovsx install xavier-arosemena/roo-plus
```

또는 영어 README의 [빠른 시작](../../README.md#quick-start) 섹션을 따라 소스에서 빌드합니다.
