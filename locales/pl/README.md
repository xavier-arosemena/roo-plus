Roo+ to **fork projektu Zoo Code**: asystent rozwoju AI z **90 wstępnie załadowanymi trybami niestandardowymi** z katalogu **301 trybów**, a także z obsługą **MCP** i **ponad 25 dostawcami**.

## Instalacja

1. Otwórz **VS Code** lub **VS Codium**.
2. Przejdź do **Rozszerzeń** (`Ctrl+Shift+X` / `Cmd+Shift+X`).
3. Wyszukaj **"Roo+"**.
4. Kliknij **Zainstaluj**.

Albo zainstaluj go bezpośrednio z wiersza poleceń:

```bash
ovsx install xavier-arosemena/roo-plus
```

Albo zbuduj go ze źródeł, postępując zgodnie z sekcją [Szybki start](../../README.md#quick-start) w angielskim README.
