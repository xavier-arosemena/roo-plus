Roo+ est un **fork de Zoo Code** : un assistant de développement IA avec **90 modes personnalisés préchargés** issus d'un catalogue de **301 modes**, plus la prise en charge de **MCP** et **plus de 25 fournisseurs**.

## Installation

1. Ouvre **VS Code** ou **VS Codium**.
2. Va dans **Extensions** (`Ctrl+Shift+X` / `Cmd+Shift+X`).
3. Recherche **"Roo+"**.
4. Clique sur **Installer**.

Ou installe-le directement depuis la ligne de commande :

```bash
code --install-extension xavier-arosemena.roo-plus
ovsx install xavier-arosemena/roo-plus
```

Ou compile-le à partir du code source en suivant la section [Guide de démarrage rapide](../../README.md#quick-start) du README en anglais.
