Roo+ 是 **Zoo Code 的一个分支**：一款 AI 开发助手，内置来自 **301 个模式目录**的 **90 个自定义模式**，并支持 **MCP** 和 **25+ 提供商**。

## 安装

1. 打开 **VS Code** 或 **VS Codium**。
2. 进入 **扩展**（`Ctrl+Shift+X` / `Cmd+Shift+X`）。
3. 搜索 **"Roo+"**。
4. 点击 **安装**。

或者直接从命令行安装：

```bash
code --install-extension xavier-arosemena.roo-plus
ovsx install xavier-arosemena/roo-plus
```

或者按照英文 README 的[快速入门](../../README.md#quick-start)部分从源码构建。
