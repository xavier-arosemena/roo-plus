Roo+ は **Zoo Code のフォーク**です。**301 モードのカタログ**から **90 のカスタムモード**をプリロードした AI 開発アシスタントで、**MCP サポート**と **25 以上のプロバイダー**を備えています。

## インストール

1. **VS Code** または **VS Codium** を開きます。
2. **拡張機能** に移動します（`Ctrl+Shift+X` / `Cmd+Shift+X`）。
3. **"Roo+"** を検索します。
4. **インストール** をクリックします。

または、コマンドラインから直接インストールします:

```bash
code --install-extension xavier-arosemena.roo-plus
ovsx install xavier-arosemena/roo-plus
```

または、英語版 README の [クイックスタート](../../README.md#quick-start) セクションに従ってソースからビルドします。
