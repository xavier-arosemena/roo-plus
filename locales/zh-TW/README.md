Roo+ 是 **Zoo Code 的一個分支**：一款 AI 開發助手，內建來自 **301 個模式目錄**的 **90 個自訂模式**，並支援 **MCP** 和 **25+ 提供者**。

## 安裝

1. 開啟 **VS Code** 或 **VS Codium**。
2. 進入 **擴充功能**（`Ctrl+Shift+X` / `Cmd+Shift+X`）。
3. 搜尋 **"Roo+"**。
4. 點擊 **安裝**。

或直接從命令列安裝：

```bash
ovsx install xavier-arosemena/roo-plus
```

或依照英文 README 的[快速入門](../../README.md#quick-start)部分從原始碼建置。
