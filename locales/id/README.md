Roo+ adalah **fork dari Zoo Code**: asisten pengembangan AI dengan **90 mode kustom yang sudah dimuat** dari katalog **301 mode**, plus dukungan **MCP** dan **25+ penyedia**.

## Instalasi

1. Buka **VS Code** atau **VS Codium**.
2. Buka **Extensions** (`Ctrl+Shift+X` / `Cmd+Shift+X`).
3. Cari **"Roo+"**.
4. Klik **Install**.

Atau instal langsung dari baris perintah:

```bash
code --install-extension xavier-arosemena.roo-plus
ovsx install xavier-arosemena/roo-plus
```

Atau bangun dari sumber kode dengan mengikuti bagian [Panduan Memulai Cepat](../../README.md#quick-start) pada README bahasa Inggris.
