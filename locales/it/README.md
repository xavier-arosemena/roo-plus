Roo+ è un **fork di Zoo Code**: un assistente di sviluppo IA con **90 modalità personalizzate pre-caricate** da un catalogo di **301 modalità**, oltre al supporto **MCP** e **oltre 25 provider**.

## Installazione

1. Apri **VS Code** o **VS Codium**.
2. Vai su **Estensioni** (`Ctrl+Shift+X` / `Cmd+Shift+X`).
3. Cerca **"Roo+"**.
4. Clicca su **Installa**.

Oppure installalo direttamente dalla riga di comando:

```bash
code --install-extension xavier-arosemena.roo-plus
ovsx install xavier-arosemena/roo-plus
```

Oppure compila dal codice sorgente seguendo la sezione [Guida rapida](../../README.md#quick-start) del README in inglese.
