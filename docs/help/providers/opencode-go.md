# Provider setup: Opencode Go

Opencode Go is a coding-agent provider that exposes its models through an OpenAI-compatible API.

> Roo+ is a GitHub-only fork and links only to Roo+ GitHub resources. Open your
> provider's own console from the provider card in **Settings → Providers** to create
> credentials; this page does not restate third-party URLs.

## What this provider is

- **How you connect** — an Opencode Go API key.
- **Default endpoint** — `https://opencode.ai/zen/go/v1`.

## Get an Opencode Go key

1. Sign in to the Opencode Go service.
2. Create an API key.
3. Choose Opencode Go in Roo+, paste the key, and save.

> Keep credentials out of your repository. Roo+ stores provider secrets in VS Code
> secret storage, not in a committed settings file.

## Configure in Roo+

1. Open **Settings → Providers**.
2. Select **Opencode Go** from the provider list.
3. Provide the credential or endpoint described above.
4. Confirm the base URL (default `https://opencode.ai/zen/go/v1`) if the field is shown.
5. Choose a model (see below) and press **Save**.

## Recommended models

- `glm-5.2`
- `kimi-k3`
- `deepseek-v4-pro`
