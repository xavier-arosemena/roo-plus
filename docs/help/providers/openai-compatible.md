# Provider setup: OpenAI Compatible

OpenAI Compatible connects to any endpoint that speaks the OpenAI Chat Completions API.

> Roo+ is a GitHub-only fork and links only to Roo+ GitHub resources. Open your
> provider's own console from the provider card in **Settings → Providers** to create
> credentials; this page does not restate third-party URLs.

## What this provider is

- **How you connect** — the base URL your endpoint uses, plus an API key if it requires one.

## Point Roo+ at your endpoint

1. Choose OpenAI Compatible in Settings → Providers.
2. Enter the Base URL of your endpoint.
3. Paste an API key if your endpoint requires one, then save.

> Keep credentials out of your repository. Roo+ stores provider secrets in VS Code
> secret storage, not in a committed settings file.

## Configure in Roo+

1. Open **Settings → Providers**.
2. Select **OpenAI Compatible** from the provider list.
3. Provide the credential or endpoint described above.
4. Choose a model (see below) and press **Save**.
