## 🟢 Now — building

### Cost-aware coding

Your assistant spends real tokens; you should always know what it costs — and stay in control.

- **Spending visibility** — see what each task costs, up front and as it runs.
- **Simple budgets** — set a "low / medium / high" budget in one click; the assistant pauses with a clear choice before costs run away. No configuration required.
- **Honest numbers** — transparent cost breakdowns so you know exactly where your tokens go.

### Smarter mode discovery & onboarding

300+ specialised modes are only powerful if you can find the right one.

- **Guided quickstart** — get to your first successful task in minutes, even if you've never configured an AI tool.
- **Smart recommendations** — "which mode should I use?" answered in plain language, based on what you're working on.

---

## 🔵 Next

### A safer "trust middle"

Keep the developer in control without stopping your flow.

- Review what the assistant wants to do in a **non-blocking panel** — approve, reject, or edit inline while you keep coding.
- Routine actions run automatically; anything risky **waits for your explicit approval** (no silent "auto-approve everything").

### Workflow integrations

Meet agents where your work already lives.

- **GitHub-first**: link tasks to issues, open PRs from completed work, and keep a project board in view.

## The principles behind all of it

- **Local-first, bring-your-own-model, user-controlled.** No mandatory cloud, ever.
- **Honest about cost.** Never hidden, never surprising.
- **Trust ladder:** visible → supervised → autonomous. No silent auto-approval.
- **Standard-compatible** (AGENTS.md / CLAUDE.md). Your files stay yours — no lock-in.
